# TrekMateBackend

This is the backend scaffold for TrekMate Nepal. It uses Express, MySQL, JWT authentication, password hashing, and file uploads.

## Project structure

- `config/` - database and environment configuration
- `controllers/` - request handlers and business logic
- `middleware/` - reusable middleware for authentication, error handling, uploads, and more
- `models/` - database access and data models
- `routes/` - Express routers grouped by resource
- `uploads/` - uploaded files storage
- `utils/` - helper functions such as async error handling
- `app.js` - Express application setup
- `.env` - environment variables
- `.gitignore` - ignored files and folders
